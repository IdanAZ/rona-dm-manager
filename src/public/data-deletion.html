מחיקת נתונים

עודכן ב־20 בנובמבר 2026 (Asia/Jerusalem).

כך אפשר לבקש שנמחק נתוני פלטפורמה ששמרה אפליקציית Rona DM Manager:

  1. הסירו את האפליקציה בפייסבוק: הגדרות ← אפליקציות ואתרים. אם תשלחו משם בקשת מחיקה, Meta תפנה לכתובת ה-callback שלנו.
  2. או כתבו בקשה חופשית לכתובת שמופיעה בהגדרות האפליקציה אחרי הפריסה, וציינו את שם המשתמש באינסטגרם או מזהה העמוד.
  3. או התנתקו מהחשבון במסך «חשבון» באפליקציה.

לאחר הבקשה נמחק אסימונים, תגובות, נמענים ויומני שליחה הקשורים לחשבון. אם יישאר קוד אישור, אפשר לבדוק סטטוס בכתובת שתוחזר בתשובת ה-callback.

Data Deletion · Rona DM Manager

Updated 20 November 2026 (Asia/Jerusalem).

You can request that we delete Platform Data stored by Rona DM Manager in any of these ways:

  1. Remove the app in Facebook: Settings → Apps and websites. If you send a deletion request there, Meta will call our data-deletion callback.
  2. Email a deletion request using the contact method listed in the live app settings, and include the Instagram username or Page ID.
  3. Sign out and disconnect the Instagram account from the app’s Account screen.

After a request we delete tokens, comments, recipients, and send logs associated with the account. If a confirmation code is issued, you can check status at the URL returned in the callback response.
